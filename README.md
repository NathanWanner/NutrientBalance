R Scripts:
•	NutrientBalance_Aggregate_Outputs_2025.R – This R script calls auxiliary scripts and creates the core dataset for the nutrient balance.  The script calls Feed.R, NutrientBalance_Inputs_2025.R, NDeposition_2025.R, Item_Aggregates_Nutrients_2025.R, Seed_2025.R, and Volatilisation_Leaching.R to create the output Data_Output_10Nov2025.csv
o	Feed.R – reads the feed data from the old and new feed balance sheets (FBS) methodologies.  The script calculates the dry matter feed intake requirements according to IPCC methodology by livestock category.  The feed data taken from the FBS is subtracted from the intake requirements to have an estimate of removal from pasture.  The pasture removal quantities are then converted to nutrients, using the nutrient uptake percentages for Bermuda grass.  These calculations are not currently used for dissemination, but are included for extension to agricultural land.
	Datasets:  Feed_Old_Methodology.csv – Feed data from FBS old methodology prior to 2010 reference year;  Feed_New_Methodology.csv – Feed data from FBS new methodology from 2010 to most recent reference year; Emissions_livestock_E_All_Data_(Normalized).gz – Livestock stock numbers by livestock category
	Data tables:  IPCCregions_areas.csv – the IPCC country/region classifications; 
o	NutrientBalance_Inputs_2025.R – reads the manure and mineral fertilizer data and standardizes them.  
	Datasets:  Inputs_FertilizersNutrient_E_All_Data_(Normalized).csv – the most recent release of the fertilizers data in FAOSTAT; IFA_countries_2025.csv – the most recent release of the IFA fertilizers dataset; Emissions_livestock_E_All_Data_(Normalized).gz – the Emissions from livestock dataset, used to access the Manure applied to soils (N content) which is net of losses from manure management.  The same dataset is used to access the manure left on pasture, which is not currently used for dissemination but included for extension to agricultural land.   For the nutrients P and K, the treated manure is accessed from the dataset, with the implicit assumption that there are no losses from manure management for these nutrients.  These manure quantities are used to calculate P and K, using the ratios of these two nutrients to N, by livestock category.
	Data tables:  Manure_Nutrient_Ratios_Updated_2.csv – the ratios of P and K to N by livestock category.
o	NDeposition_2025.R  - reads the nitrogen deposition rates and converts them to quantities by multiplying by the area of cropland.
	Datasets:  Inputs_LandUse_E_All_Data_(Normalized)_2024.csv – the 2024 dissemination of the Land Use dataset in FAOSTAT; N_Deposition_2024.csv – Nitrogen deposition rates by country/year
o	Item_Aggregates_Nutrients_2025.R – Standardizes the nutrient uptake coefficients by crop, and gap fills the missing nutrient/crop combinations using a weighted average of area harvested data by crop group
	Datasets: Production_Crops_Livestock_E_All_Data_(Normalized).gz – the most recent production dataset disseminated in FAOSTAT, used to access the area harvested data
	Data tables:  Nutrient_Removal_Updated_3.csv – the nutrient removal coefficients by crop used to access the N, P, and K uptake coefficients;  Item_Group_Updated.csv – FAOSTAT crop group hierarchy 
o	Seed_2025.R – reads the seed utilization data from the FBS for the old and new methodologies and coverts quantities to nutrients.  This R script is auxiliary, as the final calculation is done later in processing.
	Datasets:  Seed_Old_Methodology.csv – Seed utilization data from the old FBS methodology prior to 2010 reference year;  Seed_New_Methodology.csv - Seed utilization data from FBS new methodology from 2010 to most recent reference year
	Data tables:  Item_Group_Updated.csv - FAOSTAT crop group hierarchy 
o	Volatilisation_Leaching.R – reads the volatilization and leaching data from manure applied to soils, manure left on pasture, and synthetic fertilizers
	Datasets:  Emissions_livestock_E_All_Data_(Normalized).gz – used to take more recently disseminated volatilization and leaching data for manure applied to soils and manure left on pasture;  Emissions_crops_E_All_Data_(Normalized).gz – used for the most recently disseminated data for volatilization and leaching for synthetic fertilizers
•	Crop_Residuals_Removal_Calculate_Disseminate_3.R – reads the crop residue removal data and converts to quantities and outputs Crop_Residues_Removal_Disseminate_China_3.RData
o	Datasets:  Crop_residue_by_country.csv – used to access and standardize the crop residue removal data by nutrient (N removed with crop residue, P removed with crop residue, and K removed with crop residue).
•	AsssignFlags_Correct_EU_Additional_Elements_2025_Additional_Indicators.R – reads the output data from NutrientBalance_Aggregate_Outputs_2025.R, standardizes, computes additional indicators, and assigns flags.  The additional indicators fertilizer dependency and sustainable nitrogen management index are not disseminated.  The script outputs the datafiles ESB_2025_All_7.gz and ESB_Data_2025_7.gz
o	Datasets:  Data_Output_10Nov2025.csv – this is the output data from the R script NutrientBalance_Aggregate_Outputs_2025.R; Crop_Residues_Removal_Disseminate_China_3.RData – this is the output data from the R script Crop_Residuals_Removal_Calculate_Disseminate_3.R;
o	Data tables:  FAO_Country_Group_M49_No_China.csv – the aggregation composition for FAOSTAT; Country_Regions.csv – auxiliary table not used in calculations; Groups.csv - auxiliary table not used in calculations.
•	Former_Areas.R – calculates the data for the former areas, including the USSR.  The input data is ESB_Data_2025_7.gz and the output data is ESB_Data_2025_With_Former_Areas_4.gz, which is the final dataset used for QAQC and dissemination.  Data for the formers areas are directly taken from Land Use, Fertilizers, and manure datasets and are calculated for the others.
o	Datasets:  ESB_Data_2025_7.gz – dataset output from the script AsssignFlags_Correct_EU_Additional_Elements_2025_Additional_Indicators.R; Inputs_LandUse_E_All_Data_(Normalized).csv – Land Use dissemination dataset 2025. Inputs_FertilizersNutrient_E_All_Data_(Normalized).csv – used to ensure that flag assignment is consistent with the fertilizers data disseminated in FAOSTAT. 
o	Data tables:  m49.csv – the M49 country coding classification; areas_merge_modified.csv – the hierarchy for the former areas
•	QAQC_2025.R -  Quality Assurance Quality Control (QAQC) script used to generate plots.
•	QAQC_2025_Reduced.R – Quality Assurance Quality Control (QAQC) script used to generate plots for disseminated data.
Auxiliary Functions:  
	Data_Aggregate.R – used to assign complete time series for present day countries for aggregation purposes using data for former areas.
	Data_Aggregate_Biodiversity_2025 - used to assign complete time series for present day countries for aggregation purposes using data for former areas.  The script allows for discontinuation of crops within present day countries.
	multiple_line_charts.R – used for generation of QAQC plots
